# Air Cairo Hurghada Web Campaign

Self-contained web campaign generated from the approved campaign assets.

## Output
- index.html: responsive interactive campaign viewer
- assets/desktop: 16 flattened 16:9 campaign slides
- assets/mobile: 8 vertical 9:16 social creatives
- assets/media: 30-second campaign reel and PDF deck
- assets/fonts: local Poppins fonts

## Interaction
- Desktop: 16-slide presentation
- Mobile/portrait: 8-story vertical creative sequence
- Previous/Next controls, keyboard arrows and swipe
- Optional autoplay
- Reel modal
- PDF access

## Local preview
Open index.html in a modern browser.

## Publishing
This folder is static and can be published directly to GitHub Pages, Cloudflare Pages, Netlify or any standard web host.
